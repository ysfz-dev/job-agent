Autofill

Drag the button to your bookmarks bar. On any job application page, click it — it fills what it recognises, outlines each field, and leaves the rest to you.

Fill Application

Setting it up

  1. Press Ctrl+Shift+B to show the bookmarks bar
  2. Drag the teal button onto it
  3. Open a job application, click the bookmark
  4. Read every field, fix anything wrong, submit yourself

Left blank on purpose

github, website, noticePeriod, salaryExpectation, authorizedInCountry, requiresSponsorship

These are the questions that get applications auto-rejected, and the right answer changes per posting — notice period, salary, and whether you need sponsorship in that country. A script guessing them is worse than a blank field, so it flags them amber and stops. Set them in src/profile.js under application once you have decided, then re-run node src/build-autofill.js.

Why this instead of a bot

This is ordinary JavaScript running on a page you opened, in your own browser — the same thing a password manager does. There is no automation framework driving the session, so navigator.webdriver stays false and there is nothing for a site's bot detection to find. You stay the one who reads the form and presses submit, which is also the part worth keeping a human on.
